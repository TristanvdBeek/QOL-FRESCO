# QOL-FRESCO

This repository contains some python scripts used to improve quality of life for [FRESCO](https://github.com/hjwijma/fresco) by hjwijma and [pyFRESCO](https://github.com/kt-korbeld/pyFRESCO) by kt-korbeld. fetchPDBs.py is used to fetch the PDB files generated by FoldX based on a .tab file with the mutations within cutoff, as produced by DistributeRosetta and DistributeFoldX from FRESCO. ManagerMultiSeededMD.py manages running the molecular dynamics simulations for FRESCO. ManagerMultiSeededMD.py needs an installation of YASARA Dynamics and the MultiSeededMD.mcr from FRESCO. ManagerMultiSeededMD is used for local simulations and is not the ideal solution to running the simulations on a high-performance cluster.
